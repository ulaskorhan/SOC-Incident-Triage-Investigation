# SOC Incident Triage & Investigation Lab

A hands-on Security Operations Center (SOC) investigation project focused on alert triage, log analysis, incident reconstruction, IOC investigation, MITRE ATT&CK mapping and response recommendations.

## Objective

The objective of this project is to investigate simulated security alerts using a structured SOC workflow.

The investigation focuses on determining whether observed activity represents legitimate behaviour, a false positive, or a potential security incident.

## Investigation Workflow

1. Alert triage
2. Initial assessment
3. Log analysis
4. Event correlation
5. IOC investigation
6. Incident timeline reconstruction
7. MITRE ATT&CK mapping
8. Severity assessment
9. Response recommendations
10. Incident documentation

## Scenario

A Windows workstation has generated an alert related to suspicious PowerShell activity.

The investigation will examine the available evidence to determine:

- What happened?
- Which host and user were affected?
- What processes and events were involved?
- Are there indicators of compromise?
- Which MITRE ATT&CK techniques are relevant?
- Does the evidence support treating the event as a security incident?
- What actions should a SOC analyst recommend?
